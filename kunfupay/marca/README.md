# Marca Kunfupay · logos

Sacados de kunfupay.com el 20/10/2026 (`/images/logo-kunfupay-completo-white.png`, `/images/logo-kunfupay-simple.png` y `/images/redesign/kunfupay-mark-white.svg`).

- `logo-kunfupay-fondo-claro.png`: cuadrado morado con «ku» en blanco y «kunfupay» en casi negro (#1B1B1F). Para fondos claros (pizarras, papel, viñetas).
- `logo-kunfupay-fondo-oscuro.png`: el mismo, con «kunfupay» en blanco, tal cual lo publica la web. Para fondos oscuros.
- `logo-kunfupay-simbolo.png`: solo el cuadrado con «ku». Para pegatinas o huecos pequeños.
- `kunfupay-mark-white.svg`: el «ku» en vectorial, sin el cuadrado. Morado de marca: #734BFC (la web también usa #845EEE).

Cómo se puso en los estáticos de Tributaless V07: en las viñetas, el modelo de imagen pinta el logo en la camiseta del socorrista con este archivo como referencia; en pizarras, calendarios y fichas, se pega el archivo exacto (imán, impresión o pegatina) para no deformarlo.
